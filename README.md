# The Grand Tour

Sandra's 50th and Bray's 30th, October 16 to 29, 2027. A family invitation site served by GitHub Pages from `docs/`.

- `docs/index.html`: the invitation page.
- `docs/rsvp/`: the response page. Add `?demo=1` to try it without saving anything.
- `docs/og.png`: the link preview card. Edit `og/og.html`, then re-render with
  `PLAYWRIGHT=file:///E:/exodus-price-sync/tripapp/node_modules/playwright/index.mjs node og/render.mjs`.
- `supabase/grand_tour.sql`: run once in the Supabase SQL editor so responses save.
- `BRAND.md`: colors, type, voice.
